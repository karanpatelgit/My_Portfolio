My Analysis Process

A consistent workflow across every data project.

🎯

1. Define the Question

Start with a clear business or research question before touching any data.

🧹

2. Clean & Prepare

Handle missing values, outliers and inconsistencies using pandas.

🔍

3. Explore (EDA)

Distributions, correlations, patterns — no assumptions skipped.

📊

4. Visualise

Charts that communicate clearly — Matplotlib, seaborn, Tableau or Power BI.

💡

5. Interpret & Report

Actionable insights written in plain language, backed by numbers.

🔄

6. Iterate

Refine based on feedback; analysis is never one-and-done.

"Without data you're just another person with an opinion." — W. Edwards Deming. This drives my approach: every conclusion must be traceable back to evidence.
